# Detector mechanics

- [Baseline SolidWorks assembly](baseline-assembly/) contains the existing `Montaj1.SLDASM` and its companion parts from the repository's Hardware branch. Keep the files in one directory when opening the assembly.
- [Revised parts](revised-parts/) contains the later individual SolidWorks parts from the project archive.
- [Print exports](print-exports/) contains 3MF files from the later prototype iteration. The front plate export predates the latest front plate CAD file. Re-export from the CAD model if you need the latest geometry.

The baseline assembly and the revised parts represent separate iterations.
